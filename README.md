# CV Digest

A morning reading digest on computer vision, models and GPU/CUDA, written by a scheduled Claude task every weekday at 8:29 AM (Montreal time), with a small web UI to browse it.

## Layout

```
daily/YYYY-MM-DD.md     one digest per weekday (written by the scheduled task)
monthly/YYYY-MM.md      monthly roundups (reserved for later)
index.json              list of all digests, regenerated by scripts/build_index.py
index.html, vendor/     the web UI (static, no build step, no external requests)
```

To add another section later, create the folder, add its name to `SECTIONS` in `scripts/build_index.py`, and add a tab in `index.html`.

## Serving it on your tailnet

On the always-on machine:

```sh
git clone git@github.com:Witaek/cv-digest.git ~/cv-digest
cd ~/cv-digest
```

The repo is private, so this machine needs read access: a read-only
[deploy key](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/managing-deploy-keys)
is the cleanest option.

### 1. Keep the clone up to date

Add a cron entry (`crontab -e`) that pulls every 10 minutes:

```
*/10 * * * * cd ~/cv-digest && git pull --ff-only --quiet
```

Or run `scripts/sync.sh` as a long-running service if you prefer (it pulls every 5 minutes).

### 2. Serve the folder

With Docker:

```sh
docker compose up -d        # http://<machine>:8080
```

The bundled nginx config refuses to serve `.git` and other dotfiles.

Without Docker, any static server works, for example `python3 -m http.server 8080`.
That one will also serve `.git`, which is fine inside a tailnet you trust but worth knowing.

### 3. Open it from your devices

Visit `http://<machine-name>:8080` from anything on your tailnet. For HTTPS and a nicer URL,
`tailscale serve --bg 8080` exposes it at `https://<machine-name>.<tailnet>.ts.net`, tailnet-only.
