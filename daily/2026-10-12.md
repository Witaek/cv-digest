## Top papers

- **Domain Adaptation of SAM 2.1 for Building-Component Segmentation in Image-Based 3D Reconstruction** — [link](https://arxiv.org/abs/2610.12786). Adapts SAM 2.1 to segment building parts (walls, windows, structural elements and the like) in photos, then uses the masks in image-based 3D reconstruction. Check the abstract for which parts of SAM are tuned (decoder only, adapters, or full), how many labeled images it took, and the mIoU gain over zero-shot SAM 2.1.
- **Why DiT Models Underperform as Representation Learners without Long Skip Connections** — [link](https://arxiv.org/abs/2610.13344). Per its title, the gap between diffusion transformers and U-Net diffusion models as feature extractors comes down to the U-Net's long skip connections. It is relevant if you are considering diffusion features for dense prediction (depth, segmentation, correspondence) instead of DINO- or SigLIP-class encoders.
- **WAPR: A Foundation Model for Wide-Angle Refinement in Unseen Object Pose Estimation** — [link](https://arxiv.org/abs/2610.09535). *(Late last week.)* A pose-refinement model for objects not seen in training, aimed at cases where the initial pose estimate is far off. It sits in the same slot as the FoundationPose-style refiners used in bin picking and robotic grasping.
- **LVSPM: Long Sequence View Synthesis and Pose Estimation Model** — [link](https://arxiv.org/abs/2610.10960). Jointly estimates camera poses and renders novel views over long image sequences. It is relevant if you run 3D reconstruction from video without a separate SfM step.
- **A Real-World CAD Segmentation Benchmark: Comparing Rule-Based and Learning-Based Approaches through Hole Detection** — [link](https://arxiv.org/abs/2610.13466). A benchmark on real CAD models that compares classic rule-based geometry processing with learned segmentation, using hole detection as the test task. Niche, but a fair head-to-head of rules versus learning is rare in industrial inspection work.

## News

- **Auditing VLM Benchmarks from Existing Evaluation Runs** — [link](https://arxiv.org/abs/2610.13548). Proposes finding broken or noisy benchmark items from evaluation runs that already exist, with no new annotation. It pairs with last week's finding that an empty mask can beat SAM 3 on some video segmentation evaluations.
- **Dino Forcing Flow Models** — [link](https://arxiv.org/abs/2610.11751). A generative paper, included only because it uses DINO features as the target: it has the flow model skip denoising whatever a DINO encoder can predict. It is another sign that self-supervised encoders are becoming the shared representation for generation as well as perception.

## Today's deep read

**Domain Adaptation of SAM 2.1 for Building-Component Segmentation** — [link](https://arxiv.org/abs/2610.12786).

- **What to read:** which SAM 2.1 components are tuned and how many parameters change, the size of the labeled set, how prompts are generated automatically (points, boxes, or a detector in front), and the gap to zero-shot SAM 2.1 and to a conventional segmenter trained on the same data. Also check whether the masks measurably improve the downstream 3D reconstruction, or only the 2D metrics.
- **How it could apply to you:** most production uses of SAM are this shape. A general promptable model meets a narrow domain whose classes it was never told about. If you maintain such a pipeline, compare the paper's tuning recipe and label budget with yours. Also check whether automatic prompting, rather than mask quality, is the real bottleneck. That is usually where zero-shot SAM pipelines fail on industrial imagery.
